# S城新闻沙盘

八年级语文“新闻单元”互动教学网页。

这是一个纯前端本地项目，使用 HTML、CSS 和原生 JavaScript 实现，不需要后端、数据库、登录系统或联网。直接打开 `index.html` 即可运行。

## 主要文件

- `index.html`：网页入口
- `style.css`：基础布局、地图、线索流、详情区域
- `enhancement.css`：视觉增强
- `v1.css`：新闻日、编辑会、快讯、出版、复盘基础样式
- `desk-v2.css`：地图优先架构、特殊入口、筛选、截稿状态
- `reporting.css`：采写室、四文体写作、最终版面会议
- `data.js`：地图地点、市场快照、新闻日底层事件数据
- `reporting-data.js`：深度采写故事与材料数据
- `app.js`：全部页面状态、交互逻辑、localStorage

## 打开方式

在浏览器中直接打开：

```text
index.html
```

如需教师导演模式，可打开：

```text
index.html?teacher=1
```
